# Metals campaign verification record

Date: 2026-08-02

Suggested branch: `feature/metals_enrichment_diffusion`

Suggested PR title: `feat(physics): add conservative metal enrichment and turbulent mixing`

## Delivered scope

This snapshot integrates the scalar `total_only` path into the production source runtime. It adds exact FLRW elapsed-time evaluation, age-and-birth-metallicity SSP tables, persistent unresolved return budgets, dimensionally consistent local deposition, conservative Smagorinsky diffusion with explicit SSPRK2 and RKL2 options, diffusion timestep participation, restart/snapshot metadata, global metal diagnostics, validation data, tests, and benchmarks.

The snapshot does **not** claim completion of the full campaign. The following hard requirements remain open and are fail-closed or documented:

- individual-element `core_elements` storage, transport, yields, and cooling;
- a licensed, calibrated production yield table;
- cross-rank stellar enrichment target discovery and deposition;
- same-level inter-patch, coarse-fine reflux, and MPI-boundary metal diffusion;
- conservative momentum deposition;
- a complete full-workflow enrichment-plus-diffusion restart/MPI validation deck.

## HDF5 verification

Commands:

```bash
cmake --preset hdf5-debug
cmake --build --preset build-hdf5-debug -j12
ctest --test-dir build/hdf5-debug \
  -R 'metal|stellar|feedback|cooling|restart|snapshot|hdf5|config_examples' \
  --output-on-failure
```

Environment: HDF5 1.14.5.

Result: full HDF5 build passes. The focused test set is 23/24 pass. The failure,
`integration_restart_equivalence_reference_workflow_hydro`, is reproducible in
the pristine input repository and predates this campaign: its test fixture
contains a gas-tagged particle without an authoritative gas-cell sidecar row.
Two other inherited HDF5-suite failures were independently reproduced in the
pristine tree: `integration_reference_workflow_hydro_row_order` has the same
fixture defect, and `unit_ic_reader` contains a stale expectation that
`Metallicity` is unsupported. The campaign-specific snapshot, restart, SSP,
feedback, diffusion, cooling, and configuration tests pass in the HDF5 build.
