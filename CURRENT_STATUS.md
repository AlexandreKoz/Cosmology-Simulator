## Configuration policy

Simulation inputs, examples, release profiles, fixtures, and normalized copies
use lower-snake-case `.param.txt`. YAML and JSON are not accepted simulation
configuration formats. JSON remains valid for generated metadata and reports.
The authoritative decision is
`docs/architecture/adr_param_txt_configuration_format.md`.

## Provisional or unavailable capabilities

- Production hierarchical local timesteps and adaptive global timesteps are
  unsupported in the reference workflow.
- Rank-count-changing restart and asynchronous output are unsupported.
- Distributed IC import is provisional when MPI+HDF5 are enabled and still
  requires its dependency-complete rank matrix.
- Heavy/provisional diagnostics require explicit opt-in.
- Large-rank scaling, publication-grade cosmology validation, GPU production
  certification, calibrated AGN, element-resolved metals, and cross-rank or
  coarse-fine metal mixing are not claimed.
- Optional MPI, FFTW, CUDA, and Python gates are only valid when their
  dependencies are present; a disabled or unavailable dependency is not a pass.
